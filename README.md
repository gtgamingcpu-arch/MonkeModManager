# MonkeModManager

# 🦍 Monke Mod Manager

**Monke Mod Manager** is a simple, modern, and easy-to-use mod manager designed to make installing, managing, and organizing mods for **Gorilla Tag** as painless as possible.

Whether you're completely new to modding or already have a massive collection of mods, Monke Mod Manager aims to provide a clean experience without requiring users to manually dig through game folders and move files around.

> 🦍 **Less folder digging. More monke.**

---

## ✨ Features

### 📦 Easy Mod Installation

Install mods without manually navigating through your Gorilla Tag installation directory.

Monke Mod Manager handles the tedious parts of mod installation, allowing you to spend less time managing files and more time actually playing.

### 🔄 Mod Updates

Keep track of your installed mods and update them when newer versions become available.

The goal is to make keeping a modded Gorilla Tag installation up to date as simple as possible.

### ⚙️ Automatic Setup

Monke Mod Manager is designed to handle as much of the setup process as possible automatically.

The less configuration users have to do manually, the better.

---

## 🎮 Built for Gorilla Tag

Monke Mod Manager is specifically designed with the **Gorilla Tag** modding community in mind.

From utilities and quality-of-life modifications to completely ridiculous monke-related additions, the goal is to make managing a modded Gorilla Tag installation accessible to everyone.

> **⚠️ Note:** Mods are third-party content and are not affiliated with or endorsed by Gorilla Tag or its developers unless explicitly stated.

## 🚀 Getting Started

### 1. Download

Download the latest version of **Monke Mod Manager** from the repository's **Releases** page.

### 2. Launch

Run the application after downloading it.

Depending on your system configuration, Windows may display a security warning for applications downloaded from the internet.

### 3. Select Gorilla Tag

Choose your Gorilla Tag installation if the manager does not automatically detect it.

### 4. Install Mods

Browse the available mods and install the ones you want.

Monke Mod Manager will take care of the necessary file management.

### 5. Launch Gorilla Tag

Once your mods are installed, launch Gorilla Tag and enjoy your newly modded experience. 🦍

---

## 🛠️ Mod Management

Monke Mod Manager is designed around keeping your mod installation organized.

Instead of treating your Gorilla Tag folder like a dumping ground for random DLLs and files, the manager can keep track of what has been installed and make future management easier.

This helps with:

* Installing mods
* Removing mods
* Updating mods
* Keeping files organized
* Managing multiple modifications

---

## 🧩 Compatibility

Monke Mod Manager is primarily intended for **Windows** systems running the PC version of Gorilla Tag, Unless you use Wine.

Compatibility with individual mods may vary depending on:

* Gorilla Tag updates
* Mod dependencies
* Mod loaders
* Game version
* Other installed mods

If a mod stops working after a Gorilla Tag update, the issue may be caused by the game update rather than Monke Mod Manager itself.
